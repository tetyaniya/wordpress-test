# Space Laboratory — WordPress Technical Assessment

Демонстраційний односторінковий сайт на WordPress із власною темою, адаптивним дизайном, інтерактивними компонентами та SEO-оптимізацією.

**Live:** https://tetyaniya-wp.alwaysdata.net/

## Технології

- WordPress 6.8+, PHP 8.4, MySQL
- HTML5, SCSS, JavaScript (ES6+)
- Vite, Swiper, IMask
- Gutenberg, WordPress Customizer, Custom Post Types
- Contact Form 7, Flamingo
- All in One SEO (AIOSEO Lite)

Тема розроблена без сторонніх page builders та ACF.

## Реалізований функціонал

**Головна сторінка**

- Hero зі слайдером Swiper, заголовком і CTA.
- Секції Benefits, About, Contact Form, Contacts, FAQ.
- Адаптивне меню з якірною навігацією.
- Інформаційний popup із відкладеним показом.
- Окрема сторінка 404.

**Керування контентом**

Редагування доступне через стандартну адміністративну панель WordPress:

- Gutenberg — текстовий контент і стандартні блоки.
- Homepage Sections — налаштування секцій головної сторінки.
- Customizer → Contact Details — телефон, email, адреса та соціальні мережі.
- FAQ — окремий Custom Post Type із класичним редактором.

Соціальні посилання підтримують додавання, видалення, зміну порядку та завантаження іконок.

Контактні дані повторно використовуються в різних компонентах сайту.

**Контактна форма**

Реалізована через Contact Form 7:

- Валідація обов'язкових полів.
- Маска українського номера телефону через IMask.
- Додаткова серверна валідація номера.
- Збереження заявок через Flamingo.
- Власна JavaScript-подія `successfulSending`, яка змінює текст кнопки на 3 секунди після успішного надсилання.

**Popup**

Інформаційний банер на основі HTML `<aside>`. Показується через 15 секунд або після прокручування сторінки на 1500px. Після першого показу стан зберігається в `localStorage`, щоб не відкривати банер повторно в тому самому браузері.

## SEO та структуровані дані

Для базової SEO-оптимізації використовується AIOSEO Lite:

- Meta Title, Meta Description, Canonical URL, Robots Meta.
- Open Graph.
- XML Sitemap та robots.txt.

Мовний атрибут HTML-документа забезпечує WordPress.

Структуровані дані Schema.org реалізовані у форматі JSON-LD:

- `LocalBusiness` — інформація про демонстраційну організацію.
- `FAQPage` — автоматично формується із записів CPT `faq`.
- `BreadcrumbList` — генерується AIOSEO.
- `WebPage`, `WebSite`.

Кастомна Schema інтегрована з графом AIOSEO через фільтр `aioseo_schema_output` у `inc/schema.php`.

Оскільки сайт односторінковий, BreadcrumbList містить лише Home.

XML Sitemap та robots.txt генеруються динамічно, без створення фізичних файлів.

## Безпека

- WPS Hide Login — зміна стандартної адреси авторизації.
- Limit Login Attempts Reloaded — обмеження кількості невдалих спроб входу.

Дані авторизації та ключі підключення до сторонніх сервісів не включаються до репозиторію.

## Примітки

Space Laboratory — вигадана організація, створена для демонстрації функціоналу. Контактні дані та контент мають тестовий характер.

У репозиторії міститься SQL-дамп бази даних із демонстраційним контентом і тестовими налаштуваннями WordPress.

Проєкт виконано як тестове завдання для демонстрації навичок розробки власних WordPress-тем, інтеграції плагінів та організації редагованого контенту.
