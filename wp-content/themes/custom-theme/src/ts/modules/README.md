Модулі поведінки секцій додавайте сюди та імпортуйте з `../main.ts`.

Для двох слайдерів створіть окремі модулі Hero та About; використовуйте `swiper`
і лише потрібні модулі з `swiper/modules`. Ініціалізуйте їх тільки за наявності
відповідного елемента в DOM. На цьому етапі JS-поведінку навмисно не реалізовано.
